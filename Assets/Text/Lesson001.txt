　　準備

　　１．Unity Hubを起動し、GameAlgo2026のプロジェクトを開く

　　２．メニューの File - Save As...をクリック

　　３．Assets の中に「Lesson」のフォルダを作成し、その中に「Lesson001」フォルダを作成

　　４．Lesson001フォルダを開き、その中に、ファイル名「0511」のファイルを作成して保存
　　
　　５．メニューのEdit - Project Settings - Player - Other Settings - Active Input Handling
　　　　[InputSystemPackage(New)]から[Both]に変更
　　　　Unityエディタが再起動するかも。

　　作成

　　６．　ヒエラルキーウィンドウを右クリックし、3D Object - Cube をクリック

　　７．　プロジェクトウィンドウのLesson001フォルダをクリックして選択する

　　８．　プロジェクトウィンドウのLesson001フォルダにマウスカーソルを合わせたまま、右クリック

　　９．　Create - MonoBehaviourScriptをクリック

　　１０．スクリプト名を「CubeController0511」にする

　　１１．プロジェクトウィンドウのCubeController0511をクリックしたままドラッグし、

　　　　　ヒエラルキーウィンドウのCubeの上で離す（アタッチ操作）

　　１２．CubeController0511をダブルクリックし、VisualStudioを起動する

　　１３．Startメソッド内の中に、以下の命令を入力して保存する

　　　　　Debug.Log("CubeController0511が実行されました。");

　　１４．Unityエディタの実行ボタンをクリックし、コンソールウィンドウに以下の文字が出てるか確認する。

　　　　　「CubeController0511が実行されました。」

　　１５．Updateメソッド内に、以下の命令を入力して保存する

　　　　　transform.Rotate(0, 0, 10);// １フレームで１０度回転

　　１６．Unityエディタの実行ボタンをクリックし、くるくる回るか確認する

　　１７．Updateメソッド内に、if文を追加して保存する

          // 左クリックされるごとに１０度回転

          if(Input.GetMouseButtonDown(0))
          {
              transform.Rotate(0, 0, 10);
          }

　　１８．Unityエディタの実行ボタンをクリックし、左クリックするごとに１０度回転するか確認する

　　１９．クラス内に変数の追加、Updateメソッド内の命令を以下のように変更する

　　　　　float rotSpeed; // void Start()の１行上に追加

          // Update内の命令を以下のように変更

          // 左クリックされたら回転スタート(変数を使用)

          if (Input.GetMouseButtonDown(0))
          {
              rotSpeed = 10;
          }
          transform.Rotate(0, 0, rotSpeed);

　　考えてみよう（左クリックは０，右クリックは１）
　　※ 右クリックされたら回転を止めるようにしてみよう！！

　　チャレンジ問題（変数を徐々に小さくするには・・・）
　　※ 左クリックで回転開始、徐々に回転を遅くする。

　　スーパーチャレンジ問題（自力でスクリプト思いついたらセンスあるね！！）
　　※ 左クリックをクリックするごとに、回転、停止、回転を繰り返すようにしてみよう！！
